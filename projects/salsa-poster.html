Salsa Poster

Design

Description

A poster design for a salsa dancing event. Exploring color composition and typography to create a vibrant and energetic atmosphere.

Special attention was given to the layout to make the poster visually appealing and easy to read. The design was created first based on a Canva template and then refined using Photoshop.
